# 圏論パズル - 箱と矢印の冒険

中学生から大人まで、誰でも楽しく圏論（Category Theory）を学べるパズルゲームです。

## 🎮 ゲームの特徴

- **直感的な学習**: 箱と矢印を使って、圏論の基本概念を視覚的に理解
- **段階的な難易度**: 9つの問題を通じて、基礎から応用まで学習
- **身近な例**: ハンバーグやカルボナーラなど、料理の工程で圏論を体験
- **即時フィードバック**: 答えが正しいかその場で確認できる
- **ブラウザで動作**: インストール不要、すぐに始められる

## 📚 学べる概念

### 段0: 図で遊ぶ
- 矢印の合成（つなげる）
- 結合律（順番を変えても同じ）

### 段1: 恒等と合成
- 恒等射（何もしない矢印）
- 合成の定義
- 結合律の確認

### 段2: 四角が合う
- 可換図式（どの道を通っても同じ結果）
- 四角形と三角形の図式
- 複数経路の一致

## 🚀 使い方

### 1. ゲームを開く

ブラウザで `index.html` を開くだけ！

```bash
# ローカルサーバーを起動する場合（推奨）
python -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセス

### 2. 遊び方

1. **チュートリアルを読む**: 最初に基本的な説明が表示されます
2. **問題を確認**: 左側のパネルでヒントと目標を確認
3. **矢印を追加**: ツールボックスから「矢印」を選び、箱をクリックしてつなぐ
4. **確認する**: 「▶️ 確認する」ボタンで答えをチェック
5. **次の問題へ**: 正解したら「次の問題へ →」で進む

### 3. ツールの使い方

- **👆 選択**: 箱や矢印を選択
- **➡️ 矢印**: 箱と箱をつなぐ矢印を追加
- **🗑️ 削除**: 矢印を削除（未実装）

## 🔧 技術仕様

### フロントエンド
- **HTML5 Canvas**: 図の描画
- **Vanilla JavaScript**: ゲームロジック（フレームワーク不要）
- **CSS3**: レスポンシブデザイン

### 圏論の実装
- **グラフ構造**: 対象（Object）と射（Arrow）をMapで管理
- **経路探索**: DFSで始点から終点までのすべての経路を列挙
- **可換性判定**: すべての経路が同じ始点・終点を持つかチェック

### 主要クラス

#### `CategoryGraph`
圏（Category）を表現するグラフクラス
- 対象（箱）と射（矢印）の管理
- 経路の探索と合成
- 可換性のチェック

#### `DiagramValidator`
可換図式の検証エンジン
- 必要な矢印の存在確認
- ゴール経路の検証
- 経路の可換性判定

#### `DiagramRenderer`
キャンバス描画エンジン
- 箱と矢印の描画
- ホバー・選択状態の表示
- 経路のハイライト

#### `CategoryGame`
ゲーム全体の制御
- 問題のロードと切り替え
- ユーザーインタラクション
- スコアと進捗の管理

## 📖 圏論とは？

圏論は「もの同士のつながり方の学び」です。

- **対象（Object）**: 「モノ」を表す（例: ハンバーグ、チーズハンバーグ）
- **射（Arrow/Morphism）**: 「関係」や「変化」を表す（例: チーズを乗せる）
- **可換図式（Commutative Diagram）**: どの道を通っても同じ結果になる図

### 身近な例：ハンバーグの圏

```
ハンバーグ ──チーズを乗せる──> チーズハンバーグ
     |                                |
デミグラスをかける            デミグラスをかける
     |                                |
     v                                v
デミグラスハンバーグ ──チーズを乗せる──> デミグラスチーズハンバーグ
```

この図は「可換」です。なぜなら：
- 上回り：ハンバーグ → チーズハンバーグ → デミグラスチーズハンバーグ
- 下回り：ハンバーグ → デミグラスハンバーグ → デミグラスチーズハンバーグ

どちらも同じ「デミグラスチーズハンバーグ」に到達します！

## 🎯 教育的意義

このゲームは以下の学習理論に基づいています：

1. **ワークド・エグザンプル効果**: 見本を提示してから自力で解く
2. **テスト効果**: 思い出す練習で定着を強化
3. **間隔反復**: 同じ概念を繰り返し出題
4. **視覚化**: 抽象概念を図で表現
